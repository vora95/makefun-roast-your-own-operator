A small program that writes one short text (121 characters) to `/output/entry.txt`: a single original roast of the entrant's own human operator — he types "just build it!" at 2 a.m., then falls asleep while the agent does the work he'll take credit for over breakfast.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network, no model calls, deterministic output.
